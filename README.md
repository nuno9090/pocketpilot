# PocketPilot 1.0 starter

A responsive, static multilingual web app (English, Portuguese, German, Spanish).

## Included
- Home dashboard and responsive navigation
- Savings, monthly budget and compound-interest calculators
- Starter list of online earning platforms with official links
- Practical educational guides
- Privacy and disclaimer placeholders
- PWA manifest and basic offline cache

## Run locally
Open `index.html` in a browser. For service-worker/PWA testing, serve this folder over localhost or HTTPS.

## Publish for free with Cloudflare Pages
1. Create/sign in to a Cloudflare account.
2. Open Workers & Pages and create a Pages project using Direct Upload.
3. Upload this ZIP or the unzipped folder and deploy.
4. Test the generated `pages.dev` address on phone and desktop.
5. Add a custom domain later if desired (domain registration costs extra).

Official guide: https://developers.cloudflare.com/pages/get-started/direct-upload/

## Before public launch
- Replace placeholder contact details with a real monitored email and required publisher/legal details.
- Review privacy/cookie requirements for the countries you target.
- Verify platform availability, terms, fees and links periodically.
- Add original, useful articles. Do not copy or auto-publish unverified material.
- Add analytics only after choosing a privacy-compliant setup and providing required notices/consent.
- Apply for advertising only after the site has substantial original content and meets the ad network's policies.
- Add affiliate disclosures next to any monetized links.
- Do not present calculators as financial, tax or legal advice.

## Current limitations
No accounts, backend, newsletter, live rates, automatic news feed, payment system or ad integration. These are intentionally excluded from the low-cost first release.
